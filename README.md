# Coin Flip // Simple & Clean 3D Coin Toss

A clean, minimalist, and realistic 3D coin toss web application. Built with lightweight Vanilla HTML5, CSS3 3D transforms, and Web Audio API synthesis.

---

## ✨ Features

- **Realistic 3D Coin**: Beautiful dual-sided coin (Golden Heads & Silver Tails) with authentic 3D rim thickness, parabolic flip elevation, and dynamic ground shadow.
- **Minimalist Centered Interface**: Distraction-free, single-card layout optimized for quick decisions.
- **Built-in Procedural Audio**: Authentic whoosh and metallic clink synthesized via Web Audio API (zero external audio files or downloads needed).
- **Simple Score Counter**: Tracks Heads, Tails, and Total count with a one-click Reset option.
- **Keyboard Shortcuts**:
  - <kbd>Space</kbd> or <kbd>Enter</kbd>: Flip coin
  - <kbd>M</kbd>: Mute / Unmute audio
  - Direct click/tap on the coin or the "Flip Coin" button.

---

## 🚀 Running Locally

Launch the server with Python:

```powershell
python -m http.server 3000
```

Open your browser at:
```
http://localhost:3000
```
